## Findings

1. **P1 — The cheapest variant's expiration suppresses a still-open offer.** `backend/availability/services/refresh.py:189–209` picks the cheapest open variant at ingest, then writes its window, URL and quality as the canonical row. `backend/availability/services/reconciliation.py:290–293` subsequently evaluates only that row's window, and `backend/tracker/services/availability_reads.py:108–112` drops the whole presence. With two same-scope NL rents, €1.99 expiring in five minutes and €4.99 with no reported end, `GET /api/movie/481980/availability/?current_country=NL` first returns €1.99 as source-reported and returns zero offers ten minutes later. The €4.99 variant remains in PostgreSQL. The reverse price order leaves the offer visible but incorrectly keeps `is_from=true` because `reconciliation.py:558–564` uses `window_open_at_observation`. Preserve normalized variant bounds and evaluate them at read time within their source observation. Keep the presence while any same-scope variant is open and choose its display price and link from currently open variants. Calculate `is_from` from the remaining valid prices in the chosen currency. Keep the original timestamps, unverified provenance, legacy empty-variant path, and rule excluding JustWatch-only expiry from confirmed departure alerts. Regression tests are `test_representative_expiry_does_not_hide_remaining_open_variant` and `test_from_flag_uses_variants_open_at_read_time`.

2. **P1 — Offline replay credits a contradictory edge to a reviewed title.** `backend/availability/services/issue97_collection.py:159–175` merges every typed edge sharing the selected native ID but validates title and year only on exact-TMDb edges. An edge for the same native ID with omitted TMDb ID, year 2024, title “Unrelated Edition” and an extra rental is credited to the reviewed Inception (2010) scope as `observed_fixture_offers`. Check every edge admitted to the reviewed native group for nonempty conflicting title/year before recording its offers. Keep the explicit typed anchor requirement and support genuinely missing metadata. A contradictory group should remain unresolved under the reviewed evidence contract. The regression test is `test_offline_reviewed_anchor_rejects_conflicting_labels_on_coalesced_edge`.

3. **P2 — Production title/year fallback drops variants from partial edges.** `backend/availability/sources/justwatch.py:311–336` establishes a unique native ID from the complete fallback edge, checks all same-native claims for typed ID/scope conflict, and then concatenates offers only from the title/year-matching subset. An otherwise compatible edge for that native ID with blank title/year and a separate price silently disappears from the application response. Use complete title/year anchors to resolve one native ID, then include compatible same-native edges whose missing metadata does not contradict the anchor. Retain all competing native, typed scope, and bad ID rejections. The regression test is `test_partial_edge_keeps_variants_after_title_year_fallback_resolves_native_id`.

4. **P2, present on master — A distinct TMDb season ID hides a valid season-level observation.** `backend/availability/sources/justwatch.py:258–261,626–628` writes the child external ID to the discovered content and the parent TMDb series ID to the canonical offer. The mapping in `backend/availability/services/refresh.py` therefore points the native season to a different ID from its offer. `backend/availability/services/reconciliation.py:277–280` treats it as a mismatch, and the series endpoint drops the row. The same fixture fails on verified master and the PR: parent 481991, mapped child 481992, zero season 1 reports. Keep the native season ID and season slot, explicitly associate the offer mapping with its confirmed parent series, and preserve the child TMDb ID as separate evidence. Add regression coverage when handling this existing identity gap. The regression test is `test_child_tmdb_id_is_distinct_from_parent_key_used_by_season_read`.
